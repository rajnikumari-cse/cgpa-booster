
# 🎓 CGPA Booster

CGPA Booster is a student-friendly academic dashboard that helps students track their semester performance, monitor academic goals, and organize study tasks in one place.

## 🌐 Live Demo

🚀 **[View CGPA Booster Live](https://rajnikumari-cse.github.io/cgpa-booster/)**

## ✨ Features

- 📊 **Academic Dashboard** – View academic statistics and performance summaries.
- 📝 **Semester Tracker** – Add and manage semester-wise SGPA records.
- 🎯 **Target Tracker** – Set an academic target and monitor progress.
- 📈 **Performance Chart** – Visualize academic performance using Chart.js.
- ✅ **Study Planner** – Add study tasks, set priorities, and track completion.
- 💾 **Local Storage** – Save records and tasks in the browser.
- 📱 **Responsive UI** – Designed for desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser Local Storage

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Add semester records, set your target, and manage study tasks.

## 🎯 Project Objective

The goal of CGPA Booster is to simplify academic progress tracking by combining semester records, goal monitoring, performance visualization, and study planning in a single dashboard.
